# Screen mockups

Phone screens, 390×844, static. Generated by `screens/gen.py` into one `.dc.html` per
screen; `png/` holds headless-Chromium renders.

Direction: 1970s bench instrument. Deep teal ground, cream text, orange for the thing you
act on or the number you were looking for, teal for structure. `HomeCream` is the same
home screen on a cream ground, as the alternate.

Type: DM Serif Display (wordmark, step titles) · Atkinson Hyperlegible (UI) ·
JetBrains Mono (every number).

Palette (dark): bg `#0e1c1d`, panel `#152a2b`, hairline `#2a4a4b`, text `#f1e9d8`,
muted `#93aaa8`, teal `#2fa7ab`, orange `#e8912b`.
Palette (cream): bg `#f3ecdd`, panel `#fbf6ea`, hairline `#d7cbb3`, text `#0e1c1d`,
teal `#1a7f86`, orange `#d9821a`.
